# PalmOS Motion Designer Asset List

Purpose: prepare a compact asset pack for a 30-second PalmOS explainer video.

Style direction:

- Dark, premium, technical, minimal.
- Use PalmOS black UI, white line/logo treatment, and small Palm green/yellow accents.
- Keep Solana, Palm USD, XMTP, and Umbra references visible but secondary to PalmOS.

## Core Brand Assets

- PalmOS logo, transparent background: `assets/logo.png`.
- White logo version for dark backgrounds.
- Black logo version for light backgrounds.
- Icon-only PalmOS mark.
- Current Twitter/X banner image.
- Brand color references:
  - Black / near-black UI background.
  - White / off-white typography.
  - Palm green/yellow accent.
  - Subtle Solana/PUSD accent where useful.

## 30-Second Script

0-3s:

> AI agents are starting to buy APIs, data, and services.

3-7s:

> But giving agents wallets with no rules is dangerous.

7-13s:

> PalmOS gives every agent a governed Palm USD wallet on Solana.

13-21s:

> Every payment goes through policy: agent request, vendor check, budget check, approval when needed, then PUSD settlement.

21-27s:

> Operators get the full control plane: agents, services, approvals, transactions, and audit trails.

27-30s:

> PalmOS. Payment infrastructure for autonomous agents.

## Storyboard

1. Open with abstract agent/API/data/service nodes moving toward a wallet.
2. Show the risk: a wallet without limits, then a policy boundary appearing around it.
3. Reveal PalmOS as the control plane.
4. Animate the payment flow:
   `Agent request -> Policy check -> PUSD payment -> Approval if needed -> Audit trail`.
5. Cut into real dashboard screenshots/cards.
6. End on the PalmOS logo and final line.

## Notes For Designer

- Prioritize real dashboard UI over abstract visuals.
- Keep text minimal on-screen; the product flow should do most of the explaining.
- Do not make the video feel like a generic crypto promo.
- The core message is control: agents can spend, but only inside operator-defined rules.
- Keep Umbra as a privacy/private-settlement signal, not the main product promise.
