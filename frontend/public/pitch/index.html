The decision

Three outcomes. Every call.

The policy engine compiles each agent's rules and resolves every paid call to exactly one of three states.

executed

Auto-approve

Within budget, on an allowlisted vendor, under the per-call cap.

→ Settles instantly in PUSD
approval_pending

Hold for approval

Over the threshold or flagged as risky — pauses for an operator.

→ Waits for a one-click decision
blocked

Block

No budget left, or the vendor isn't allowlisted.

→ Never settles. Recorded anyway.

Integration

Drop it into any agent.

Claude Code, Codex, or a custom worker — connect with a credential and call pay(). PalmOS handles policy, approvals, settlement, and audit.

Claude CodeCodexCustom workers
agent.ts
import { PalmosAgentClient } from '@palmos/agent'

const palmos = PalmosAgentClient.fromEnv()

// one call — policy, approval & settlement handled
const { result } = await palmos.pay({
  serviceId: 'local.pusd.spot_price',
  idempotencyKey: 'run-2026-05-29-btc',
  request: { base: 'BTC', quote: 'USD' },
})

switch (result.kind) {
  case 'executed':         // settled in PUSD
  case 'approval_pending': // awaiting operator
  case 'blocked':          // policy stopped it
}
